# GMS kNN 差距诊断：摘要

相同 1,024 个查询对象上，BS 历史原生接口离群率 **0.98%**，历史头接 Stage 4 canonical 输入为 **36.82%**。32 个查询对象的新推理与历史归档逐值一致；全量结果按 ID 复用历史预测。

BS 新头从硬标签 **21.13%** 改为 sigma3 后为 **3.40%**；原生输入上的新 sigma3 头为 **1.61%**。数值 MLP sigma3 为 **2.29%**，原光度 kNN 为 **2.54%**；MLP 与 kNN 的配对差异为 -0.24 pp (paired galaxy 95% CI -0.90 to +0.33 pp)。训练型头另用 256 个开发标签，kNN 不使用开发标签。

最后 token 欧氏 kNN：BS **6.97%**，B0 **13.15%**；BS 平均池化 kNN **2.73%**；BS 原生输入的隐藏空间 kNN 为 **1.99%**。几何表现依赖所选读出，不能直接等同于骨干信息总量。

原 kNN 精确复现；无共享身份或已识别的历史监督曝光。常数中位数离群率 34.44%，打乱特征—红移配对后平均 37.98%，支持光度与对象红移关联确实有用。未发现泄漏，不等于证明不可能有未识别的泄漏。

该查询集此前已检查，整个研究为回顾性诊断。BS 历史头拥有 22,444 个历史光谱训练标签；接口、头容量和既有监督共同变化，不能把误差差距拆成精确因果比例。
