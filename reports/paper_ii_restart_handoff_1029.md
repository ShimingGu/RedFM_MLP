# Paper II 重启交接：BS 原生接口与少样本读出（2026-10-29）

当前决定：暂不启动新的大规模 Stage 5。保留以下三项已在 GMS 回顾性诊断中验证的设置；需要重启 Paper II 的 CLAUDS 泛化实验时，再在新的巡天数据上测试。GMS 的结果不能直接代表 CLAUDS。

## 1. BS 原生 serialization：必需基准

保留历史 BS 模型原始的 tokenizer、HSC grizy flux/error 与 EBV 字段、顺序、数值格式、末尾 token、512-token 上限、last nonpadding-token pooling 和原始 300-bin 红移网格。原生接口是 BS 的必需基准；新的共同输入格式应作为单独对照记录。

同一 1,024 个 GMS 查询对象，BS 历史头在原生接口下离群率 0.98%，接 Stage 4 canonical 特征为 36.82%。历史测试预测按 ID 全量对齐，并对 32 个查询对象重新推理，logits/PDF 与归档逐值一致。BS 历史模型此前使用了 22,444 个光谱训练对象。

重启跨巡天实验时，先核对新巡天是否能忠实提供原接口所需的观测字段、单位、滤波器和 EBV。若只能构造字段映射或有缺测，应明确记录这是目标巡天到原接口的适配及其限制；不要把缺测伪装成真实测量，也不要称其完全等价于源巡天原生数据。

## 2. σ3 soft-label head：少样本读出基准

保留 Stage 4 的新头：冻结骨干特征，2560→32→300，SiLU、dropout 0.1；在 0–4.5 的 300 个 bin 上，以真实红移所在的整数 bin 为中心构造并归一化 σ=3 bin 的高斯软标签。按固定开发集上的 hard CE 选择检查点；特征标准化仅拟合支持集。保留 hard-label 头与数值 MLP 的对应对照。

GMS、K=256 时，BS canonical 新头的硬标签离群率为 21.13%，σ3 为 3.40%；原生 BS 特征上的 σ3 新头为 1.61%。这些新头每次使用 256 个训练标签，另用 256 个固定开发标签进行检查点选择。σ3 是此网格上的 3 个 bin，不是泛化到任意红移网格的固定物理宽度。

## 3. Native frozen features + kNN：轻量校准候选

保留 BS 原生输入的冻结 last-token 特征和 K-only 标准化欧氏距离；使用 k=10、均匀邻居权重及固定红移 KDE，K=256 的 GMS 查询离群率为 1.99%。KDE 使用邻居红移、高斯核和支持集决定的带宽；点预测取 PDF 中位数。该候选使用 256 个支持标签、没有开发标签调参，仍继承 BS 的历史光谱后训练。

这一条件与 Stage 4 的工程化光度 kNN 不同：后者使用测光数值特征与逆距离权重，GMS 离群率 2.54%。两者应分别保留，不要把 1.99% 归给原光度 kNN。

## 重启时的最低要求

- 在读取新查询集结果前锁定上述接口、读出、kNN 距离/权重和对照；记录任何目标巡天字段映射与缺测。
- 使用此前未检查的独立 CLAUDS 光谱对象，核对历史训练/验证曝光和重复对象；同一对象用于模型间配对比较。
- 报告训练和开发标签的实际预算，保留强数值 MLP、光度 kNN、简单常数基线；分别报告离群率、NMAD、概率质量和逐星系配对不确定性。
- 明确巡天覆盖、亮度与红移选择；明亮光谱子样本的结果只适用于该子样本。已知基础模型预训练曝光不可完全排除。

现有 GMS 研究是已检查查询集上的回顾性分析。σ3 和原生特征 kNN 是经该条件验证的候选配置，不是已证明可在 CLAUDS 泛化的方法。
